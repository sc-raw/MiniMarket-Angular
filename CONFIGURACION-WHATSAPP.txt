==============================================================
  MiniMarket - Guía de Configuración WhatsApp Business API
==============================================================

Este documento explica cómo correr la integración de WhatsApp 
localmente usando la App de Meta ya configurada por el equipo.

==============================================================
  PASO 0: Requisitos previos (Base de Datos y Credenciales)
==============================================================
1. Tener MySQL instalado y corriendo.
2. Crear una base de datos vacía llamada DBMiniMarket.
3. En MiniMarket/src/main/resources/ copia el archivo 
   application.properties.example a application.properties.
4. Pide a tu compañero el Token de WhatsApp y el Phone Number ID,
   y pégalos en tu application.properties junto con tu 
   contraseña de MySQL.

==============================================================
  PASO 1: Exponer localhost con ngrok
==============================================================

Meta necesita una URL pública (HTTPS) para enviar los mensajes.
Como trabajamos en localhost, usamos ngrok.

1. Descargar ngrok: https://ngrok.com/download
2. Crear cuenta gratuita y conectar tu authtoken:
     ngrok config add-authtoken TU_TOKEN_NGROK
3. Ejecutar:
     ngrok http 8080
4. ngrok te dará una URL nueva como:
     https://abc123.ngrok-free.dev
5. Copia esa URL, la usarás en el paso siguiente.

==============================================================
  PASO 2: Actualizar Webhook en Meta (¡Obligatorio!)
==============================================================

Como cambiaste tu URL de ngrok, debes decirle a Meta que te 
envíe los mensajes a tu nueva PC.

1. Entra a Meta for Developers (con la cuenta del equipo).
2. Ve a WhatsApp → Configuration → Webhook.
3. Click en "Edit".
4. Callback URL: https://TU-NUEVO-NGROK.ngrok-free.dev/api/whatsapp/webhook
5. Verify Token: minimarket_verify_token_2026
6. Click en "Verify and Save".

==============================================================
  PASO 3: Agregar su número de prueba
==============================================================

Para que Meta permita que su celular reciba respuestas del bot, 
su número debe estar en la lista de permitidos.

1. En el dashboard de WhatsApp → API Setup.
2. Sección "To" → Click en "Add Phone Number".
3. Agreguen su número de celular personal y verifíquenlo con el SMS.

==============================================================
  PASO 4: Probar el flujo
==============================================================

1. Arrancar backend Spring Boot (puerto 8080).
2. Arrancar frontend Angular (npm start en el puerto 4200).
3. Asegurarse de que ngrok esté corriendo.
4. Enviar un mensaje de WhatsApp desde su celular al número 
   de prueba de Meta.

El bot responderá:
  "¡Hola! 👋 Bienvenido a MiniMarket.
   ¿Qué deseas hacer?
   1️⃣ Hacer un pedido
   2️⃣ Tengo una duda"

Inicia sesión como atencion1 / atencion123 en Angular
y verás los pedidos en el dashboard de Atención al Cliente.

==============================================================
  ARCHIVOS IMPORTANTES
==============================================================

Backend:
  application.properties  → Poner token y phone-number-id del equipo
  WhatsAppServiceImpl     → Lógica del bot
  WhatsAppRestController  → Webhook + gestión de pedidos

Frontend:
  pedidos-whatsapp/       → Dashboard de Atención al Cliente
  whatsapp.service.ts     → Service Angular
